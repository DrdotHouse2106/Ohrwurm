# Ohrwurm

Verwaltet eine private Musiksammlung mit dem Katalog von Apple Music als Vorlage: Künstlerseiten wie bei Apple Music, Wunschliste auf Liedebene, jedes Lied nur einmal, Einsortieren neuer Dateien. Anschlüsse lassen sich über eine einfache Schnittstelle anbinden.

Stand: Konzept. Details in [KONZEPT.md](KONZEPT.md).
